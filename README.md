# Fluent Python Exercises

My solutions, notes, and experiments while studying **Fluent Python** by Luciano Ramalho.

This repository contains Python exercises and examples that help me understand Python's language features, data structures, object-oriented programming, and advanced concepts.

## 📚 About the Book

**Book:** *Fluent Python*  
**Author:** Luciano Ramalho  
**Language:** Python 3

The goal of this repository is to develop a deeper understanding of Python by writing code, solving exercises, and experimenting with the concepts covered in the book.

## 📂 Repository Structure

```text
Fluent-Python/
├── README.md
├── chapter01/
├── chapter02/
├── chapter03/
└── ...
```

Each chapter directory contains relevant exercises, code examples, and notes.

## 🎯 Learning Goals

- Understand Python's core data model.
- Explore built-in collections and data structures.
- Learn comprehensions, generators, and iterators.
- Practice functions, decorators, and closures.
- Understand object-oriented programming in Python.
- Explore operator overloading and special methods.
- Learn type hints, protocols, and other advanced Python features.
- Write clean, readable, and Pythonic code.

## 🛠️ Requirements

- Python 3.10 or later (depending on the examples).
- A code editor such as Visual Studio Code.
- Git for version control.

Check your Python installation:

```bash
python --version
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd "Fluent Python"
```

Run an exercise:

```bash
python path/to/exercise.py
```
